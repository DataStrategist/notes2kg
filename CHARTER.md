# knowledge_graph Charter

> Overview: [README.md](README.md)

## What this is

Network graph construction tool using Excel and R. Provides a simple, extensible way
to create knowledge charts from structured Excel input. Internal tooling for
visualising entity relationships.

---

## Current usage

Lightweight - not a production pipeline, no scheduled jobs. Used on an ad-hoc basis
to build network visualisations from tabular data.
